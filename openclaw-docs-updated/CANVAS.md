# PHASE C.1 — NATIVE INTEGRATION ARCHITECTURE (ARYEO ↔ GHL)

## Integration Strategy
The connection between Aryeo and GoHighLevel will be built using **direct webhooks and API calls**, not third‑party middleware.

**Reasoning:**
- Eliminates dependency on Zapier or Make
- Reduces cost and latency
- Increases reliability and scalability
- Enables future OpenClaw or custom app control

This establishes a **true system‑level backbone**, not a patched automation.

---

## Event Flow — Booking Creation

### Trigger
New appointment or order created in Aryeo.

### Native Actions
1. Aryeo webhook sends booking payload to a secure endpoint.
2. Endpoint processes and normalizes:
   - Client name
   - Email and phone
   - Property address
   - Services ordered
   - Shoot date and time
3. Endpoint calls **GoHighLevel API** to:
   - Create or update contact
   - Create opportunity in Listing Media pipeline
   - Attach custom fields for property and services
4. Endpoint triggers **ClickUp task creation** with:
   - Client info
   - Address
   - Services
   - Assigned photographer

**Result:**
A single booking automatically generates the **entire operational project structure**.

---

## Event Flow — Media Upload Complete

### Trigger
Dropbox folder receives final raw media or edit export.

### Native Actions
1. Dropbox webhook notifies integration endpoint.
2. Endpoint updates ClickUp status → Ready for Edit or Ready for Delivery.
3. Endpoint optionally posts notification to editor channel.

**Result:**
No human coordination required to begin editing or delivery.

---

## Event Flow — Final Delivery

### Trigger
Editor marks project complete in ClickUp **or** final files uploaded to delivery folder.

### Native Actions
1. Endpoint calls GoHighLevel to:
   - Send delivery email/SMS
   - Trigger payment request workflow
   - Move opportunity to Completed stage
2. GoHighLevel automation starts:
   - Review request
   - Repeat booking nurture

**Result:**
Revenue, reviews, and retention occur automatically.
