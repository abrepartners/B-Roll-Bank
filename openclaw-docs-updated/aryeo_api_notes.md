# Aryeo API Reference - Key Endpoints

The Aryeo API covers the following resource areas:
- Addresses
- Appointments (scheduling)
- Company Users
- Customer Users
- Discounts
- Listings
- Notes
- Order Forms
- Order Items
- Orders (invoicing/billing)
- Payroll
- Products
- Scheduling
- Tags
- Tasks
- Videos

Key areas for integration:
- Orders: invoicing, billing, order management
- Appointments/Scheduling: shoot scheduling, calendar management
- Listings: property media galleries
- Products: service catalog
- Tasks: production workflow
- Videos: media delivery

Also supports webhooks for real-time event notifications.
Authentication via API key (ARYEO_API_KEY available in environment).
