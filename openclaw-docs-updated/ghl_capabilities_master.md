# GoHighLevel Complete Capabilities Map

## Core Platform Features

### CRM & Pipeline Management
- Unlimited contacts and sub-accounts
- Pipeline management with custom stages
- SmartLists for contact segmentation
- Contact tags, custom fields, engagement scoring
- Opportunity tracking (create/update/remove)
- Contact followers for team visibility

### Communication Channels (ALL NATIVE)
- Email (send, templates, campaigns)
- SMS (2-way, bulk)
- Phone calls (outbound, call tracking, call recording, power dialer)
- Facebook Messenger
- Instagram DM
- WhatsApp
- Google My Business messaging
- Live chat widget
- Voice AI chat widget

### Social Media (Social Planner)
- Connect: Instagram, Facebook, Google Business Profile
- Schedule posts across all platforms
- Calendar and list views
- Custom platform editing (same post, tweak per platform)
- Best Time to Post feature (AI-powered)
- Advanced analytics (weekly performance, key metrics)
- Post from mobile app
- Content AI for generating captions/copy

### Website & Funnels
- Drag-and-drop website builder
- Funnel builder (Funnel AI builds in seconds)
- Form builder
- Survey builder
- Landing pages
- Blog builder

### Appointments & Calendars
- Calendar booking system
- One-time booking links
- Appointment status management (rescheduled, no show, completed)
- Eliza AI appointment booking (automated scheduling conversations)

### Payments
- Stripe integration (one-time charges via workflow)
- Invoice creation and sending (automated)
- Documents and contracts (send from templates)
- Payment collection on funnels/forms

### Automations (Workflow Builder)
- **Triggers**: Contact events, form submissions, appointments, payments, tags, custom events, webhooks
- **Contact Actions**: Create, find, update, tag, assign, DND, notes, tasks, copy, delete
- **Communication Actions**: Email, SMS, call, Messenger, Instagram DM, WhatsApp, GMB, Slack, live chat, internal notifications, review requests
- **Data Actions**: Webhooks (send data to external apps), Google Sheets
- **Logic**: If/Else branching, Wait steps, Goal events, Split testing, Go To (cross-workflow), Arrays, Drip mode, Text formatter, Custom code
- **AI Actions**: AI Prompt (GPT-powered), Conversation AI, Workflow AI
- **Eliza Actions**: AI appointment booking, Eliza Agent Platform
- **Opportunity Actions**: Create/update/remove opportunities
- **Payment Actions**: Stripe charge, send invoice, send documents/contracts
- **Marketing Actions**: Google Analytics, Google AdWords, Facebook Custom Audiences, Facebook Conversion API
- **Affiliate Actions**: Add/update/manage affiliates and campaigns
- **Courses Actions**: Grant/revoke course offers
- **IVR Actions**: Gather input, play message, connect call, end call, record voicemail
- **Communities Actions**: Grant/revoke group access

### AI Features (6 AI Tools - "AI Employee")
1. **Voice AI**: Answer inbound calls, qualify leads, book appointments automatically. Speech recognition + NLU.
2. **Conversation AI**: Chatbots that handle customer inquiries across SMS, email, Facebook, Instagram, WhatsApp, live chat. Can be trained on custom data.
3. **Reviews AI**: Auto-respond to Google reviews, boost reputation, climb search rankings.
4. **Funnel AI**: Build sales funnels in seconds with AI.
5. **Content AI**: Generate campaign-ready copy, designs, and ideas. Text + images.
6. **Workflow AI**: AI-powered automation that runs smarter. AI Prompt action (GPT-powered) generates responses within workflows.

## What CANNOT Be Done in GHL (Needs External Tools)

| Task | Why Not GHL | Recommended Tool |
|---|---|---|
| Advanced project management (Kanban, subtasks, time tracking) | GHL tasks are basic | ClickUp |
| Photo/video editing and gallery delivery | Not a media platform | Aryeo |
| Advanced financial reporting/reconciliation | Basic invoice only | Stripe dashboard + Bookkeeper agent |
| Graphic design creation | Content AI is text-focused | Designer agent + Canva/AI generation |
| Advanced phone system (call routing, voicemail transcription) | GHL has basic calling | Quo (OpenPhone) |
| Git/code repository management | Not a dev tool | GitHub |
