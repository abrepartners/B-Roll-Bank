# OpenClaw Advanced Research: Routing & Initiative

## Model Tiering Strategy
- **Tier 1 (Frontier)**: Use for main agent, complex reasoning, and architecture. (e.g., GPT-4o, Claude 3.5 Sonnet).
- **Tier 2 (Mid-Tier)**: Use for sub-agents and daily work. (e.g., GPT-4o-mini, Deepseek R1).
- **Tier 3 (Cheap)**: Use for heartbeats and simple classification. (e.g., Gemini Flash, GPT-4o-mini).

## Initiative & Autonomy
- **"Initiative during heartbeats"**: The term for the agent taking action during its periodic check-ins without user prompts.
- **Autonomous Agency**: The mindset shift from "responding to questions" to "monitoring and executing."
- **Recursive Delegation**: The Orchestrator spawning sub-agents to handle parallel tasks.

## Configuration Patterns
- **`SOUL.md`**: Must include instructions for "Autonomous Initiative" and "Team Orchestration."
- **`MODELS.md`**: A guide for the Orchestrator to select the right model for the right task to optimize costs.
- **`USER.md`**: Defines the relationship and communication style (Thomas, Direct/Concise).
