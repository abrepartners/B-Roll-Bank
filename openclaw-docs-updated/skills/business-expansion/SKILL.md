# Business Expansion (The Strategist)

This skill runs strategic business review and expansion planning for Engine E (Expansion to New Revenue).

## Progressive Disclosure
- Start with this file only.
- Always read `CANVAS_INDEX.md` sections R.1–R.11 (revenue plan) before any strategic analysis.
- Read `CANVAS_INDEX.md` sections K.1–K.6 (KPIs) when measuring current performance.
- Read `CANVAS_INDEX.md` sections E.1–E.6 (expansion architecture) when evaluating new revenue streams.
- Read `CANVAS_INDEX.md` sections H.1–H.6 (hiring roadmap) when assessing org capacity.
- Read `KNOWLEDGE.md` sections 1 (Mission), 9 (Strategy), 11 (Threats), 13 (Key Relationships) for strategic framing.

## Workflow

1. **Trigger**: Spawned by Orchestrator with latest Analyst and Coordinator data for weekly review or strategic question.
2. **Assess revenue position**: Compare current trajectory against $750k target (Canvas R.1).
3. **Identify highest-leverage opportunity**: Based on current Canvas execution phase, identify the single most impactful action available this week.
4. **Check Canvas alignment**: Verify recommended actions match the current execution phase (Section 10).
5. **Threat check**: Review Canvas Section 11 threats — flag if any are becoming active.
6. **Return**: Strategic brief (see report-back format below).

## Strategic Filters

Before recommending any action, apply these filters in order:

1. Does this move Thomas closer to owning only Vision + Expansion + Authority?
2. Does this protect or accelerate the path to $750k?
3. Does this build retainer MRR, not just one-off revenue?
4. Does this increase AOV, volume, or both?

If a recommendation fails any filter, it is not the highest priority.

## Definition of Done

A complete strategic brief includes: current revenue vs. target, top opportunity identified, recommended single action for the week, Canvas execution phase confirmation, and any active threats. Maximum 300 words — no long analysis.

## Report-Back Format

```
STRATEGIST BRIEF — [DATE]
Revenue Position: $[WTD] / $14,400 target | $[MTD] / $62,500 target
Canvas Phase: [current phase]

Top Opportunity: [one sentence]
Recommended Action: [one specific action for Thomas or the team]
Canvas Alignment: [section reference]

Active Threats: [list or NONE]
Next Phase Trigger: [what needs to happen to advance to the next phase]
```
