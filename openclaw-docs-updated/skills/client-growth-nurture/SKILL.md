# Client Growth & Nurture (The Copywriter)

This skill handles all outbound client communication drafting for Engine C (Client Growth to Retention).

## Progressive Disclosure
- Start with this file only.
- Read `KNOWLEDGE.md` sections 2 (Voice), 3 (Sales), 5 (Communication), 6 (Difficult Clients), 12 (Pricing) before drafting any message.
- Read `CANVAS_INDEX.md` sections C.1–C.5 only when designing a full nurture sequence.
- Do NOT duplicate Aryeo transactional emails (booking confirmations, reminders, delivery notices). Aryeo handles those automatically.

## Communication Rules

1. **Brand Voice**: Confident, direct, professional. No filler phrases ("just checking in", "hope you're doing well"). Lead with value or purpose.
2. **No Exclamation Marks**: Unless celebrating a specific client win.
3. **Never Discount**: If price comes up, reframe value. Never reduce pricing.
4. **Never Decline**: Route non-standard requests to Thomas as expansion opportunities.
5. **Personalize**: Always include property address when referencing a specific listing.

## Workflow

1. **Trigger**: Spawned with a specific communication goal (follow-up, review request, upsell, newsletter).
2. **Identify type**: Post-delivery follow-up / Review request / Upsell offer / Re-engagement / Newsletter.
3. **Load voice rules**: From `KNOWLEDGE.md` sections 2, 3, 5 before writing.
4. **Draft**: Write message(s) following brand voice. Keep SMS under 160 characters. Email subject lines under 50 characters.
5. **Return**: Draft(s) for Thomas's approval — never send directly.

## Message Types

| Type | Trigger | Channel | Key Goal |
| :--- | :--- | :--- | :--- |
| Post-Delivery Follow-Up | Project marked complete | Email | Gratitude + review request seed |
| Review Request | 24–48h after delivery | SMS | Get Google review |
| Upsell Offer | After 2nd booking | Email/SMS | Introduce retainer or next tier |
| Re-engagement | 60+ days since last booking | Email | Book next listing |
| Newsletter | Weekly/Monthly | Email | Education + authority building |

## Definition of Done

All drafts include: recipient name, property address (if applicable), channel, subject line (if email), and body text. All require Thomas's approval before sending.

## Report-Back Format

```
COPYWRITER DRAFT — [TYPE] — [DATE]
Recipient: [Name]
Channel: [Email / SMS]
Subject: [subject line, if email]
---
[Body text]
---
Status: AWAITING THOMAS APPROVAL
```
