# Creative Designer (The Designer)

This skill handles creative asset design briefs for Engine C (Client Growth) and Engine E (Expansion).

## Progressive Disclosure
- Start with this file only.
- Read `KNOWLEDGE.md` sections 2 (Voice), 8 (Ideal Client), 12 (Pricing) before any brand asset work.
- Read `CANVAS_INDEX.md` section R.9.6 when creating listing package flyers.
- Read `CANVAS_INDEX.md` section R.10.2 when creating retainer/branding package assets.
- Read `CANVAS_INDEX.md` sections E.1–E.2 when working on studio or digital product visuals.

## Design Principles

1. **Brand Tone**: Professional, confident, premium. Assets should signal authority, not budget.
2. **Simplicity**: Clean layouts. The property or agent is the hero, not the design.
3. **Consistency**: Maintain Avery & Bryant visual identity across all assets.
4. **Platform-Specific**: Size and format correctly for each platform (see specs below).
5. **All designs require Thomas's approval** before delivery to clients.

- **Cinematic Package** ($425): Full suite. Premium, video-forward design.
- **Luxury Package** ($600+): Custom design treatment.

## Workflow

1. **Trigger**: Spawned with asset name, purpose, audience, and any provided brand elements.
2. **Load brand rules**: From `KNOWLEDGE.md` section 2.
3. **Draft design brief**: Specify layout description, colors, typography guidance, image placement, copy text, CTA.
4. **Return**: Complete design brief for production (or attach file if asset is created).

## Definition of Done

A complete design brief includes: asset name, dimensions/format, platform, purpose, layout description, copy text, CTA (if any), and caption (for social). All require Thomas's approval before client delivery.
